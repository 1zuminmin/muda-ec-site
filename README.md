# 伊見内商会

サイトURL：**[https://iminai-shokai.pages.dev/](https://iminai-shokai.pages.dev/)**

GitHubのユーザー名が入らないCloudflare Pagesで公開しています。設定方法は、[Cloudflare Pagesの公開手順書](docs/CLOUDFLARE-PAGES.md)を参照してください。

「あなたのお金を、全力で無駄にする場所」。架空の所持金を稼ぎ、無用な品を集める無料のジョークサイトです。実際の支払い・入金・換金・配送・継続課金はありません。

## 起動方法

WindowsのPowerShellで、このリポジトリのフォルダを開いて実行します。

```powershell
./start-preview.ps1
```

ブラウザで **http://localhost:8080/** を開いてください。終了は `Ctrl+C`。ポートを変えるなら `./start-preview.ps1 -Port 8081`。追加インストールやビルドは不要です。付属サーバーはループバック限定のローカル確認用です。

スクリプトの実行が制限される環境では、VS CodeのLive Serverなどの静的ファイルサーバーを利用できます。HTMLのダブルクリックでも表示できますが、`file://` ではブラウザによりページ間でlocalStorageを共有できないため、HTTP起動を推奨します。ホスト名・ポート・ブラウザを変えると別の保存領域になります。

## できること

- **トップの商品スライダー**：通常9商品を左右ボタン・矢印キー・スマートフォンのスワイプで切り替えます。6秒ごとに自動切り替えします。ホバー中・フォーカス中・ページ非表示・画面外では一時停止します。`prefers-reduced-motion` が有効なら最初は自動切り替えを停止します。画像・商品名から詳細へ移動でき、隠し商品はこの展示には出しません。

- **商品一覧・詳細**：通常9種類の無用な品。通常9品の購入と通常8実績の達成を両方満たすと、隠し商品・隠し実績が同時に解放されます。確認モーダル→架空購入→成功画面。同じ品は何度でも購入できます。
- **架空レビュー**：各商品の `product.html?id=商品ID` に2件ずつ。すべて演出用の創作で、実在の購入者投稿ではありません。投稿機能はありません。
- **無駄な内職**：同じ空の封筒を「糊で閉じる→剥がして元に戻す」2段階の作業。1往復を終えたときだけ架空の報酬が入ります。封筒を右へなぞって糊付け、上へなぞって剥がす操作に対応。クリック・タップだけでは進みません。キーボード操作は作業台にフォーカスし、糊付けは→、開封は↑を0.7秒以上長押しして離します。Enter・Spaceや短いキー押下で作業を完了することはできません。途中で指を離す・方向を間違える・操作を中断する場合は完了しません。180ms未満の連打を計上せず、クリックイベントでは作業処理を呼びません。逆向きや横に大きく逸れた動き、完了位置から戻して離す動き、フォーカスを失った操作も完了しません。作業段階は保存され、再読み込みしても続きから遊べます。閉じる・開く両方の案内文を同じグリッド領域に重ね、必要な高さを常に確保することで、スマートフォンで折り返しが変わっても封筒の位置を動かしません。
- **封筒整列係**：周回に関係なく、現在BLACK会員であれば利用できます。「3回タップして揃える→下へフリックして散らす」の往復操作です。PCでは3回クリックしてから下へドラッグします。キーボードではEnterまたはSpaceを3回押して離し、↓を0.7秒以上長押しして離します。黒封筒は出ず、基本単価は1往復150円、2周目は1.5倍の225円です。旧版の端数フィールドは保存互換のため受け入れますが、新単価に端数は加算せず、次の整列報酬支払いで0に整理します。両方の仕事の作業段階を別々に保存し、切り替えで抽選や作業を飛ばせません。整列報酬もBLACK会員の実績に加算します。
- **2周目「徒労の継承」**：1周目の完全クリア後、マイページから任意で移行します。所持金・履歴・累計額・実績・会員・再入会権・名前・感謝状を削除し、2周目の記録と重なる封筒の紋章だけを残します。0円・未入会から再開し、通常報酬は1.5倍（15 / 30 / 75 / 150円）、黒封筒は500円固定です。紋章はヘッダー・マイページ・PNGに表示し、2周目の感謝状は御礼文も変わります。初版は2周目まで。移行前の感謝状は事前に保存してください。
- **全リセット**：周回・クリアに関係なくマイページから実行できます。周回記録と紋章も含めて削除し、1周目0円に戻ります。2周目移行と全リセットは別ボタン・別の説明を表示し、確認チェックを入れるまで確定できません。効果音の好みだけは別設定として残ります。
- **黒封筒**：1往復が終わるごとに次の封筒が1％の確率で黒封筒になります。黒封筒はどの会員ランクでも1通500円（通常報酬への上乗せではなく500円固定）。`workEnvelope` に保存し、リロードや糊付けで再抽選しません。完了時のランクの実績にも加算します。出現時には低く響く控えめなベルの効果音を合成します。未入会では会員別実績に入りません。
- **紙の効果音**：糊付け時の控えめな紙擦れ音と、開封完了時の短い「ビリッ」という音をWeb Audioで合成します。外部の音源ファイル・APIは不要です。最初の操作で音声を有効化し、効果音ON/OFFを切り替えられます。設定は `iminai:paper-sound` に別途保存し、ゲーム記録をリセットしても音の好みは維持します。音声非対応・再生拒否でも作業は継続できます。
- **会員サロン**：未入会は1往復10円、RED〈正会員〉20円、GOLD〈特別会員〉50円、BLACK〈名誉会員〉100円。剥がして作業を完了した時点のランクを適用します。入会には異なる商品の購入がRED 1種類・GOLD 2種類・BLACK 3種類必要です。同じ品を何度買っても1種類として数えます。入会金は架空通貨でRED 2,000円、GOLD 5,000円、BLACK 10,000円です。初めて入るプランには会費全額を支払い、退会・降格の返金はありません。一度入会したプランへ戻る場合は再入会0円です（カード・確認画面に明示）。購入条件は再確認します。既存会員を自動で退会・降格させることはありません。メール・カード・パスワードは不要。実際のサブスク契約・請求・自動更新はなく、会費は架空残高から減り、商品購入累計とは別の `membershipSpent` に記録します。入会済みのプランは `paidPlans` に保存します。`membershipCredit` は旧データ互換のため保持し、新規プランの割引には使いません。
- **マイページ**：右上の所持金の横からアクセス。20文字までのニックネームを登録・変更できます。保存後に生成する購入認定証・完全クリアの感謝状に「お名前 様」を記載します。未設定なら「名もなき浪費家 様」。過去の購入分も現在の保存名で再発行でき、ダウンロード済み画像は変わりません。X共有文に名前を自動で加えません。
- **会員徽章**：未入会は山形のない盾章、RED正会員は梅の花＋一段の山形、GOLD特別会員は竹葉＋二段、BLACK名誉会員は松葉＋三段・月桂樹。すべて同色の自作SVGで、形と数から会員ランクを見分けられます。実在する軍隊の記章ではありません。ヘッダー、マイページ、会員サロンに共通表示します。
- **通常8実績＋隠し実績**：購入回数・累計額・収集数・会員別の内職報酬に応じて解除。No.3はREDで10,000円、No.4はGOLDで25,000円、No.7はBLACKで50,000円を稼ぐ実績です。BLACK会員の50,000円には、封筒復元係とBLACK限定の封筒整列係の報酬を合算します。内職を完了した時点のランクにだけ加算し、未入会の報酬は対象外です。実績は最初は全8個で表示し、通常8実績と通常9品を両方揃えると、隠し実績を含む全9個に切り替えます。隠し実績は3×3の中央に配置します。
- **共有**：購入ごとの認定証PNGとX共有リンク。収集中でも累計無駄遣い額と収集数を共有できます。すべてのX共有には公開サイトURLを付け、localhostやHTML直接起動からも公開URLを共有します。公開先を変更する場合は `js/storage.js` の `siteURL` を更新してください。完全クリアの共有文には作者 `@izuko_1231` へのメンションが入り、通常の商品購入・途中経過の共有には入りません。投稿・画像添付は利用者自身が行います。対応ブラウザでは「アプリで共有」からOSの共有先一覧を開き、Xなどを選べます。Xアプリの存在や直接起動は保証せず、従来のX Web Intentリンクも残します。X APIキー・有料APIは使いません。
- **お得意様へのご案内**：通常9種類を購入し、通常8実績も達成すると「お得意様への特別なご案内です」と、10万円の隠し商品「元に戻された封筒」が出現します。解放前は商品一覧・商品詳細・購入処理から利用できません。PCでは通常9品の3×3の下、4段目中央に通常カードと同じ幅で表示し、ご案内文を左に置きます。スマートフォンでは1列で表示します。
- **PNGの保存補助**：購入成功画面・履歴・マイページ・クリア画面の「画像を開く」から `certificate.html` へ移動できます。この端末の記録からPNGを生成し、長押し保存・PNG保存リンク・画像だけを開くリンクを提供します。ファイル共有に対応した端末では画像をアプリへ渡せます。ほかの端末へこのページのURLを送っても認定証の記録は転送されません。
- **完全クリア**：隠し商品まで購入して全10種類を集めると、完了メッセージと番号なしの感謝状を表示。PNG保存・X共有・後日の再発行ができます。感謝状は最初の完全クリア時の累計額・購入数・日付を残します。
- **無駄名誉会員一覧**：作者へのメンション付きの完全クリア報告は原則掲載対象とし、作者が確認して掲載名と達成日だけを手動で公開します。掲載を希望しない方は投稿に「掲載不要」と記載します。フッター・クリア画面から案内。手順は [docs/HONOR-ROLL.md](docs/HONOR-ROLL.md)。自分のブラウザのクリア記録は個人向け表示で、公開名簿へ自動送信しません。
- **作者のボヤキ・X**：フッターから閲覧。本文は作者本人の原稿です。作者ページ・フッター・完全クリア画面に作者のXを案内します。
- **利用規約・プライバシー**：フッターから閲覧。架空購入・保存データ・実況配信の方針を記載しています。収益化した実況動画も許可し、サイト名・URLの紹介は任意のお願いとしています。

商品収集の進捗は最初は「○ / 9種類」、実績は「○ / 8個」です。通常9品の購入と通常8実績の達成が両方揃うと、商品は「9 / 10種類」、実績は「8 / 9個」へ同時に切り替わります。どちらか一方だけでは隠し要素は解放されません。マイページ・X共有文も同じ目標を表示します。

商品価格は旧版の一律5倍です。**新規プレイの初期所持金は0円**です。通常9品の合計は71,000円、隠し商品を含む完全クリアまでの合計は171,000円（商品代のみ・会費別）です。「所持金のみ0円に戻す」は資金をゼロにし、購入・内職・会員・実績・収集記録を維持します。資金を増やす機能ではありません。「すべての記録を削除」は確認後に全記録を消去し、0円からの最初の状態に戻します。

## 全クリアの会員番号について

**今回は番号を発行しません。** サイト全体で重複しない `00000001` からの連番は、サーバー側での排他的な採番と永続保存が必要なため、将来の拡張としています。ローカルだけの番号を全体順位のようには表示しません。

## 技術・データ保存

HTML5 / CSS3 / Vanilla JavaScript / localStorage / Canvas API。サイトの実行にNode.js、フレームワーク、バックエンド、データベース、外部API、外部フォント、広告は使いません。PNG保存はOSの日本語フォントを使います。`prefers-reduced-motion` に対応しています。

保存キーは旧版と同じ `muda-shokai:v1`、データ内部の `version` は9です。旧版の残高・履歴・累計額・内職報酬・会員状態・完全クリア記録を保護して引き継ぎます。バージョン3からの移行では空の名前欄も追加し、会員IDと単価も維持します。旧価格の購入履歴は当時の金額を維持します。既存会員は追加徴収なしで引き継ぎます。旧版は最高到達ランクまで無料で戻れる仕様だったため、その範囲の再入会権も引き継ぎます。更新後に初めて入るプランは全額支払い、入会済みのプランへは無料で戻れます。名前は `profile.name` として同じlocalStorageに保存します。既存の残高を勝手に0円にはしません。旧版の9商品クリア記録は「通常商品制覇」として残します。未クリアの方の隠し要素は新しい共通条件で判定し、すでに全10品を購入済みの完全クリア記録・公開範囲は維持します。最終実績と感謝状は10商品購入時に改めて獲得します。購入累計と内職報酬は別管理です。会員別の内職獲得額は `earnedByPlan` に保存します。旧版にはランク別の記録がないため、会員別の実績進捗は更新後から0円で記録します。差し替えた旧実績（return / master / worker）の解除状態は引き継がず、それ以外の実績・所持金・累計・会員・クリア記録は維持します。

ギャンブルの画面・操作・抽選APIは廃止しました。旧版の未精算結果がある場合のみ、移行時に確定済みの払戻しを一度だけ残高へ反映し、その後旧データを整理します。新しい勝負はできません。

データはこのブラウザだけに保存し、端末間同期・本人認証・改ざん防止はありません。名前はログインアカウントではなく、このブラウザだけで使う表示名です。ブラウザデータの削除などで記録が失われます。保存拒否・容量不足の場合は警告して一時モードに切り替えます。破損した記録は勝手に上書きせず保護し、利用者の全記録削除操作で初期化します。

## 文章・画像を編集するには

- **作者の話**：`author.html` の `author-copy` 内。編集範囲をHTMLコメントで挟んでいます。見出しは `<h2>` / `<h3>`、本文は `<p>` の中を書き換えます。作者本人の原稿に差し替え済みで、仮原稿の案内は削除しています。
- **作者のX**：`js/config.js` の `creatorX` に `izuko_1231` のようにユーザー名を記入します。現在は `@izuko_1231` を設定済み。空欄・不正な形式ならXへのリンクを非表示にします。`streamingPolicy` は `monetized`（収益化動画も可）/ `noncommercial`（非収益のみ）/ `pending`（確認中）。許可範囲を変える場合は `terms.html` のJavaScript無効時の本文も合わせて更新します。
- **レビュー**：`js/reviews.js` の商品IDごとの `name` / `stars` / `title` / `body`。架空である旨の表示は維持してください。
- **商品**：`js/storage.js` の `products`。履歴の整合性を保つため、販売済みの商品IDや価格の変更には移行処理が必要です。商品追加時は全クリア条件・既存感謝状の扱いも見直してください。
- **プラン**：同ファイルの `plans` の `rate` が1往復の架空報酬、`fee` が架空の入会金、`requiredProducts` が入会に必要な異なる商品の購入数です。未入会は `workRate` 内の10円を適用します。実際の課金はありません。
- **隠し商品**：同ファイルの `secret: true` の品。`regularProducts` の全品購入と通常8実績の達成を共通条件として、商品と実績の表示・購入を制御します。フロントエンドだけのゲーム演出であり、ソースから商品の存在を秘匿する仕組みではありません。
- **商品画像**：`assets/images/stone-lit.png` と各 `*-photo.png`。内蔵ImageGenで作成した新規画像。旧SVGも残しています。制作情報・プロンプトは同フォルダの `README.md` に記録しています。

## 開発用の検証

サイトの起動には不要ですが、Node.jsがある環境では依存パッケージなしで台帳テストを実行できます。


## Gitでの保存・GitHubへのアップロード

既存のリポジトリを利用し、`codex/` の作業ブランチに今回の変更をコミットして既存の `origin` にpushします。ユーザーの許可に基づき、依頼された開発は検証後にデフォルトブランチへのマージとpushまで進めます。この方針は `AGENTS.md` に記録しています。サイト公開設定は別の操作です。

```powershell
git status
git switch -c codex/your-change
# 今回変更したファイルだけを指定してステージングします。
git add FILE_PATH
git diff --cached --check
git commit -m "Describe the change"
git push -u origin codex/your-change
```

別の場所で新規作成する場合は、Git管理がなければ `git init`。GitHubで空のリポジトリを作り、`git remote -v` で既存接続先を確認し、originがなければ `git remote add origin https://github.com/YOUR_NAME/YOUR_REPO.git` で接続します。現在のブランチ名は `git branch --show-current` で確認できます。強制pushは不要です。
