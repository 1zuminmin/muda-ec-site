# 無駄名誉会員一覧の更新方法

公開ページは `honor-roll.html`、名簿は `js/honor-roll-data.js` です。サーバーや送信フォームは使わず、作者へのメンション付きのクリア報告を原則掲載対象とし、作者が内容を確認してから追記します。「掲載不要」と書かれた投稿は対象外です。未確認の方や実在しない達成者は掲載しません。

## 掲載までの流れ

1. 作者のX（`@izuko_1231`）へのメンション付きの完全クリア報告を確認します。共有文にはメンションを自動で入れますが、投稿の確定・感謝状画像の添付は利用者自身が行います。通常の商品購入・途中経過のシェアは掲載対象外です。
2. 「掲載不要」など掲載を断る意思表示があれば追加しません。完全クリアを確認し、掲載名は指定のニックネームがあればそれを優先し、なければXの公開表示名をもとに確認します。本名・個人情報を含む場合や20文字を超える場合、意思が不明な場合は本人に掲載名を確認してから追加します。ブラウザ内の記録は編集可能なので、感謝状だけで厳密な達成証明ができる仕組みではありません。
3. 名簿ファイルの配列へレコードを追加します。掲載名は20文字以内、日付は `YYYY-MM-DD` です。

```js
window.IminaiHonorRoll = Object.freeze([
  { name: '確認した掲載希望名', completedOn: '2026-11-06' }
]);
```

上記は書式例です。実際に確認した情報に置き換えてください。同じ方からの複数のシェアで二重掲載しないよう確認します。証拠画像、DM本文、本名、連絡先、Xアカウントは名簿に入れません。

4. ローカルで表示を確認し、`node --test tests/*.test.cjs` を実行します。
5. 変更をGitへコミットして公開ブランチへ反映します。ページの人数は実際のレコード数から表示されます。

連番や世界順位は付けません。掲載順は編集した配列の順です。ページには自分のブラウザのクリア記録も表示されますが、この個人向け表示から公開名簿へ自動転記・送信はしません。

## 訂正・取り下げ

本人の希望を確認し、該当レコードを修正・削除して再公開します。公開Gitリポジトリの履歴や第三者の保存分には以前の情報が残ることがあります。名前を公開する前に、この点も伝えてください。
